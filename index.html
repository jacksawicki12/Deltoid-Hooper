Cloud Sync Setup Guide & Rules Notice

To allow Jack and Courtney to view and save data from any browser or phone using this link, ensure your Firebase Firestore Security Rules in the Firebase Console allow read/write access to the collection fitness_entries:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /fitness_entries/{document=**} {
      allow read, write: if true;
    }
  }
}
